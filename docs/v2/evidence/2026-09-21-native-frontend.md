## 修复候选范围

- 给设置面板的外层挂载容器和字段明确不收缩的布局，防止设置内容绘制到下一节。
- 原有 UXP 输入框的外观、系统字体、不透明背景和高度规则覆盖数字、密码及未写 `type` 的文本字段；不匹配 checkbox、radio、file。输入框高度调整为 32px，为行高、padding 和边框留下空间。
- 专业参数根据可用宽度和 UI 缩放折行，标签左对齐。
- 配置读取、保存、删除分别提示；保存已确认而工作区刷新失败时说明实际状态。已知拒绝与结果不确定的存储故障分别处理，向外部工作区传播的错误也经过安全映射。

代码比较基线为 provider-settings PR #61 的 `73d022fe3ee9c671b1880ea1105369d2d03027e4`。该分支不包含并行的结果返修和用户预设模块；完整集成版本必须另行检查这些模块的控件。
