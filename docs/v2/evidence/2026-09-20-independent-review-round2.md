## 阶段 A：实际通过的案例

- **#63 与本机 UXP 兼容**：独立插件注册并持续连接，真实捕获、属性修改和撤销结果可返回。
- **无选区与整图**：无选区捕获明确返回 `NO_SELECTION`；显式整图捕获成功，没有静默扩大处理范围。
- **名称＋不透明度及新回执撤销**：新合成图、新捕获、新草稿修改名称并设为 60%；Photoshop 标题和原生不透明度控件与 receipt 一致。只对本轮新回执撤销一次，收到真实 `studio_rollback` 成功结果，原名称和 100% 不透明度恢复。
- **后续手动编辑保护**：另一新任务修改后，在 Photoshop 原生控件手动改为 70%；撤销返回 `ROLLBACK_CONFLICT`，70% 保持不变。
- **跨文档/关闭重开保护**：切到第二张合成图运行旧草稿被 `LAYER_CONTEXT_CONFLICT` 拒绝；原合成图关闭重开并重新建立同编号测试层后，旧草稿仍被拒绝，未新增执行任务。
- **UI→实际 Agent→UI**：UI 提交同一草稿，实际 Agent 读取 r4、仅更新名称、再次读回 r5；专业 UI 自动显示 r5 和新名称，保留原参数及上下文。该 Agent 回合未调用 Photoshop 操作。
- **真实羽化捕获**：通过 Photoshop 原生选区和 8 像素羽化捕获源图与独立蒙版；解码蒙版确认存在连续中间灰度，不是仅凭 bounds 推断羽化。

## 阶段 B：真实蒙版回贴与撤销

使用夹具提供、带 `SYNTHETIC SOURCE / TEST ONLY` 标记的纯合成图。在 Photoshop 创建大椭圆选区、减去内部椭圆孔洞、应用 8 像素羽化，再经 UI 捕获真实源图及蒙版。

默认模型、默认尺寸/比例、无参考图、关闭自动回贴。一次本机模拟响应返回带 `MOCK OUTPUT / TEST ONLY` 标记的 PNG。手动回贴后：

- 实际新增图层及图层蒙版，receipt 记录 `masked:true` 和 1:1 放置；原生位置/尺寸与捕获 bounds 一致。
- Photoshop 画布可见椭圆柔和边缘和中心透明孔洞，外围及孔洞保留源图。受管捕获蒙版具有全部 256 个灰度、81,666 个中间值像素，中心值为 0。
- 只对该新 receipt 撤销一次，服务收到成功结果；真实新图层移除，画布恢复源图外观。
- 随后的只读原生“选择”菜单显示“取消选择/重新选择”均禁用，**撤销后无活动像素选区**。没有将本次结果称为选区保留通过，也未据此单独断言违反产品约定。
- 浏览器中实际查看原输入/候选并排、B 图与 2 倍缩放；以候选为参考另建草稿，继承实际模型及参考资产。原任务快照不变，未再次执行模型或回贴。

本轮画布边缘判断来自真实 CUA 观察，并非逐像素比较 Photoshop 最终合成画面；蒙版数值检查针对真实捕获资产。
