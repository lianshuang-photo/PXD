## M0／M1 验收表

| ID | 场景 | 通过条件 |
|---|---|---|
| V01 | 套索、孔洞、羽化和部分透明选区 | 生产输入与实际 mask 对应；结果按真实边缘回贴，选区外不被覆盖 |

| V05 | 残留配方后执行接受、撤销、读回 | 不生成新请求，不额外回贴；控制操作有独立语义 |
| V06 | 供应商错误、batchPlay 错误与中途失败 | 正确错误分类，不假成功；PS 事务恢复，已生成资产保留 |
| V07 | 参数、参考图、自动回贴、编组、返回类型 | 执行采用任务开始时快照，实际结果与 UI 展示设置相符 |

| V09 | 插件／Companion 重启后恢复与重跑 | 原输入、refs、mask、参数和版本仍可追溯；缺失时明确阻止错误重跑 |
| V10 | 专业 UI 与 Agent 交替修改 | 读取同一草稿；过期 revision 不覆盖；同一 job 的候选、回贴、反馈双方可见 |
| V11 | 本地调整与真实图像编辑各一次 | 前者是 PS 真实修改，后者来自实际供应商；读回像素／回执供验收 |
| V12 | 一张 COS 样片的目标、执行与返修 | 用户可以判断是否满足角色、本人特征、范围与风格；版本可比较并定向修订 |
