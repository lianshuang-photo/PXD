## 单项完成记录

2026-09-20 V2 初批实现见 [PR #51](https://github.com/lianshuang-photo/PXD/pull/51) 和[实施状态](IMPLEMENTATION-STATUS.md)：

- B02／B13：生产抓图、真实 mask、已有层属性、受保护回执／撤销已实现；抓图、羽化、名称／不透明度与冲突已有部分真机记录，新层回贴尚待验证，编组明确不支持。
- B03／B04：共享参考资产、用途、121 配方和全部 101 数值参数已接线；真实供应商使用这些输入仍需验收。
- B08／B10：Gemini BYOK 编辑适配已实现，具备格式／尺寸限制与错误／取消测试；开发环境未配置真实供应商，不能标为真实生成交付。
- B11／B12／B33／B34：共享草稿、不可变快照、独立生成／回贴状态、候选资产、恢复与防重复已集成并测试；完整 UI↔Agent 和实际生成恢复未验收。
- B07／B32／B36：项目级两个 Skill 已更新为当前工具契约；专业页与 Agent 共用服务，UXP 面板交互及实际对话接续仍待验证。其余扩展不计为完成。

每个 Bxx 的完整交付记录仍须包含：实现 PR／commit、实际后端、UI 入口、Agent 工具、验证环境、自动化、真实输入输出及视觉验收、取消／恢复和限制。上述代码集成不等于 M0/M1 或整项能力完成。

能力优先级由 [ROADMAP](ROADMAP.md) 管理。增加／删减能力需解释产品原因；不能因某次 M1 只选一个样片，就移除其余模块。
